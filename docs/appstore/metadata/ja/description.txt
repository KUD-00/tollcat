クラウドサービス、いくつ使っていますか。Cloudflare、AWS、Vercel……それぞれに管理画面があり、それぞれに請求が来ます。今月いくら使ったかを知るには、全部にログインするしかありません。

TollCat はそれをひと目に変えます。アプリを開くと、数字がひとつ。今月ここまでに、全部でいくら使ったか。タップすれば内訳も見えます。従量の分、サブスクの分、先月より多いか少ないか。アプリを開きたくないときは、ウィジェットにも同じ数字が出ます。

■ つなぎ方
Cloudflare、AWS、Vercel、Stripe、GitHub など、80 を超えるクラウド・AI サービスに対応しています。どのサービスにも手順ガイドが付いていて、読み取り専用の API キーを作って貼り付けるだけでつながります。請求 API のないサービスには「検針ポスト」を。請求メールを転送すれば、その数字が届きます。

■ 認証情報は端末の外に出ません
API キーはこの iPhone の Keychain にだけ保存され、iCloud にもバックアップにも入りません。請求の取得は端末から各社の公式 API へ直接。間にサーバーはありません。あなたの請求は誰にも見えません。私たちにも。

■ 無料
TollCat は無料です。アカウント登録も広告もサブスクもありません。iPhone と iPad で使えます。怖い請求から救われた日には、設定にチップがあります。猫におやつをどうぞ。

スクリーンショットの数字はデモデータで、実際の請求ではありません。
