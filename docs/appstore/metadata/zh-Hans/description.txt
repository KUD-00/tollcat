你在用几家云服务？Cloudflare、AWS、Vercel……每家一个控制台，每家一张账单。想知道这个月一共花了多少，就得挨个登录去查。

TollCat 把这件事变成看一眼：打开 App，最上面就是总数——这个月到现在一共花了多少。想细看就点进去：按量的、订阅的、比上个月是多是少，都在。不想开 App 的话，小组件上也有这个数。

【怎么接入】
支持 Cloudflare、AWS、Vercel、Stripe、GitHub 等 80 多家云和 AI 服务。每家都配了一步步的接入说明，照着做就能拿到一把只读的 API 密钥，贴进 App 就接好了。有的服务没有账单接口，那就用读数信箱：把账单邮件转发给它，数字照样进来。

【凭据不出这台设备】
API 密钥只存在 iPhone 本机的 Keychain 里，不进 iCloud，也不随备份走。账单由手机直连各家官方 API，中间没有任何服务器——谁都看不到你的账单，包括我们。

【免费】
TollCat 免费，不用注册，没有广告，也没有订阅。iPhone 和 iPad 都能用。要是它哪天帮你躲过一张吓人的账单，设置里有个打赏入口，请猫猫吃点东西。
