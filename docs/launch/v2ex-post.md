标题：

> 做了个 iOS app：一眼看出这个月云服务一共花了多少，密钥不出手机

## 正文

我自己在付十来家云服务的钱：Cloudflare、OpenAI、几家数据库托管，还有些半夜脑子一热开的。想知道这个月一共花了多少，得挨个登录控制台。烦了，就做了 TollCat：打开 app，最上面就是总数——这个月到现在一共花了多少。不想开 app 的话，锁屏小组件上也有这个数。

几个 V 友大概会关心的点：

**密钥怎么存的。** API 密钥只存在手机本机的 Keychain 里，不进 iCloud，也不随备份走。账单由手机直连各家官方 API，中间没有任何服务器。项目唯一的服务端只管打赏、反馈、接入目录和读数信箱，这些路径碰不到凭据——不是「我保证不碰」，是模块链接关系上就断开的，代码可以查。

**接入麻烦吗。** 每家都配了一步步的接入说明，照着做拿到一把只读的 API 密钥，贴进去就行。只读密钥泄漏了最多让人看到你的账单，动不了你的服务。有的服务没有账单接口，就用读数信箱：把账单邮件转发过去，数字照样进来。

**收费吗。** 免费，MIT 开源，完整源码在 GitHub。设置里有个打赏入口，不打赏也一样用。

**平台。** iOS 26+，iPhone 和 iPad。安卓版还没做完，仓库里有，想搭把爪的欢迎。
